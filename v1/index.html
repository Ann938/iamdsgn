04 / Форматы

Выберите удобный формат работы

Часовая подписка

Раз в 1–2 недели присылаем отчёт по часам, вы оплачиваете подписку.

Подходит для
  • Продукты с постоянной поддержкой
  • Компании с несколькими проектами
  • Небольшие задачи
Фиксированная оплата

Считаем объём и стоимость проекта под ключ и фиксируем цену.

Подходит для
  • Лендинги и одностраничные сайты
  • Проекты без долгой поддержки
  • Проекты с фиксированным бюджетом
Месячная ставка

Долгосрочное сотрудничество с ежемесячной фиксированной ставкой.

Подходит для
  • Услуги по развитию дизайн-команды
  • Долгая поддержка проектов
  • Выстраивание процессов
